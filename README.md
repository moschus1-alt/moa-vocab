# 모아 · 나의 단어장

스페인어·일본어·중국어·영어를 네이버 사전에서 검색하고 필요한 뜻만 담는 개인용 모바일 단어장입니다. 사용자 계정 없이 이 기기의 IndexedDB에 저장합니다.

**[웹앱 바로 열기](https://moa-vocab.vercel.app)** · [GitHub 소스](https://github.com/moschus1-alt/moa-vocab) · [검수 결과](QA.md)

## 실행

Node.js 22 이상이 필요합니다. 런타임 외 별도 의존성은 없습니다.

```sh
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. `PORT` 환경변수로 포트를 바꿀 수 있습니다. 로컬 서버는 기본적으로 자신의 PC에서만 접근 가능합니다.

```sh
npm test
npm run test:live
npm run build
```

`test:live`는 실제 네이버 응답으로 네 언어, 활용형, 결과 없음의 경우를 확인합니다. 테스트 성공을 위한 샘플 사전이나 응답 대체는 없습니다. 핵심 단위 테스트의 실패 응답은 오류 처리 검증 전용이며 제품 검색에 쓰이지 않습니다.

## 사용

처음 실행하면 Duome 한국어→스페인어 과정의 고유 표현 5,363개와 대표 뜻을 기본 단어장에 넣습니다. 원본의 5,364개 중 `Chile`와 `chile`는 이 앱의 대소문자 무시 중복 규칙에 따라 하나로 합쳐집니다. 기존에 저장한 단어의 뜻과 학습 기록은 유지합니다. 기본 자료는 이 기기에 한 번만 추가되며, 삭제한 단어가 새로고침 때 되살아나지 않습니다. 단어장은 50개씩 페이지를 넘겨 볼 수 있습니다.

1. 검색에서 언어와 단어 또는 숙어를 입력합니다. 네이버 응답의 단어와 숙어 결과를 함께 표시하고, 완전 일치·앞부분 일치·포함 일치 순으로 정렬합니다. 검색 자체로 저장되지 않습니다.
2. 원하는 표제어의 + 버튼을 눌러 뜻을 선택하고 필요한 내용을 수정한 후 저장합니다.
   **단어장 → 듀오링고 과정별 단어 보기**를 누르면 한국어 사용자를 위한 스페인어·일본어·중국어 과정의 섹션·유닛별 표현을 볼 수 있습니다. 기본 단어장에 없는 표현을 선택하면 해당 언어의 네이버 사전 검색으로 이동합니다.
3. 단어장에서 수정·삭제할 수 있습니다. 같은 언어·표제어·읽기의 중복은 새 뜻과 검색어를 합치고 기존 학습 기록은 유지합니다.
   단어 옆 **발음 듣기**를 누르면 기기의 음성 합성(Web Speech API)으로 읽습니다. 네이버 녹음 음원이 아닌 기기 음성이며, 일본어는 저장된 읽는 법을 우선 사용합니다. 다시 누르면 멈추고 다른 단어를 누르면 이전 재생을 취소합니다. 기기에 해당 언어 음성이 있어야 하며 일부 음성은 인터넷 연결이 필요합니다.
4. 학습에서 **단어장 저장 순서** 또는 **듀오링고 과정별**을 선택합니다. 과정별 학습은 언어·섹션·유닛을 고른 뒤 **선택 과정만** 또는 **선택 과정까지 누적**으로 범위를 정합니다. 중복 단어는 한 번만 포함됩니다. 카드/입력 테스트, 순서/랜덤, 복습 시각이 된 단어만 학습할지도 선택할 수 있고 설정은 이 브라우저에 기억됩니다.
5. 카드 학습은 카드를 뒤집은 뒤 알아요/헷갈려요/몰라요를 선택합니다. 해석 입력 테스트는 외국어→한국어, 한국어→외국어 또는 양방향 섞기를 선택해 직접 답을 입력합니다. 정답은 대소문자와 문장부호를 구분하지 않으며 저장한 대표 뜻의 쉼표·슬래시로 나뉜 표현도 허용합니다.

알아요는 1일→2일→4일 순으로 최대 365일까지 간격을 늘립니다. 헷갈려요는 10분, 몰라요는 1분 뒤 복습 대상이 됩니다. 두 경우 이번 학습의 뒤쪽에서 한 번 더 보여줍니다. 무한 반복을 피하기 위해 같은 단어의 즉시 재등장은 회차당 한 번입니다. 매 평가 즉시 저장하며 새로고침 시 진행 중인 카드 순서는 초기화되지만 평가 기록은 남습니다.

오른쪽 위 ↥↧에서 JSON 백업/복원을 합니다. 복원은 전체 형식을 검증한 뒤 하나의 IndexedDB 트랜잭션으로 합칩니다. 기존 단어는 현재 학습 기록을 유지하고, 새 단어는 백업의 기록을 가져옵니다. 동일 백업을 여러 번 복원해도 중복 단어가 만들어지지 않습니다. 기기 간 자동 동기화는 하지 않습니다. 브라우저 데이터 삭제·기기 초기화 전에 백업하세요.

## 과정별 단어 자료

`public/data/duolingo-ko-{es,ja,zh}.json`은 [Duome의 한국어 기반 과정 목록](https://duome.eu/vocabulary/ko)에서 스페인어·일본어·중국어의 과정별 표현과 위치를 정리한 비공식 참고자료입니다.

- 스페인어: 8개 섹션, 991개 유닛, 303개 스킬, 7,114개 표현
- 일본어: 8개 섹션, 1,030개 유닛, 310개 스킬, 5,710개 표현
- 중국어: 8개 섹션, 1,030개 유닛, 310개 스킬, 6,425개 표현

스페인어의 한국어 유닛 제목은 [Duolingo Data 과정 구조](https://www.duolingodata.com/dat/esfko991.html)와 대조했습니다. 모든 과정에서 섹션 1~4는 한 유닛당 한 스킬이며, 섹션 5~8은 연속된 다섯 유닛이 하나의 단어 묶음을 공유합니다.

스페인어 과정에는 Duome의 한국어 풀이에서 간결한 대표 뜻을 골라 넣었습니다. 번역 후보가 문장별 활용형이거나 어색한 경우 일부 기초 단어는 직접 고쳤습니다. 전체를 사람이 개별 검수한 자료는 아니므로, 문맥에 맞지 않는 뜻은 단어장 수정 기능으로 고칠 수 있습니다. 일본어·중국어 과정은 기존 방식대로 사전에서 뜻을 확인해 저장합니다. 기본 스페인어 단어는 섹션·유닛 표시가 붙고 해당 유닛에서 바로 학습할 수 있습니다.

자료 갱신은 빌드와 분리되어 있습니다. 원본 구조와 개수가 바뀌면 자동으로 덮어쓰지 않고 검사를 실패시킵니다.

```sh
npm run update:course
```

스페인어 과정 자료를 갱신하면 해당 시점의 Duome 페이지를 파일로 받아 `node scripts/add-spanish-meanings.mjs 경로/es-skills.html`을 실행하여 대표 뜻을 다시 붙이세요. 새 단어를 기존 사용자에게 자동으로 추가하려면 기본 자료 버전도 올려야 합니다.

## 네이버 사전 연결

`src/dictionary/naver.mjs`가 네이버 사전 웹페이지에서 사용하는 실제 `/api3/{enko,esko,jako,zhko}/search` JSON 응답을 파싱합니다. 서버에서 네이버 사전 origin의 Referer를 포함해 POST 요청합니다. 화면의 `searchResultMap.searchResultListMap.WORD`, 별도 `IDIOM` 결과와 관련 예문을 사용합니다. 클라이언트는 자신의 origin의 `/api/search`만 호출하므로 브라우저 CORS 문제가 없습니다. 임의 URL을 전달받는 범용 프록시가 아니라 네이버 4개 사전과 100자 이하 검색어만 받습니다. 쿠키·로그인·네이버 자격증명을 전달하거나 저장하지 않습니다.

- 검색어 `query`/`queries`와 선택한 `headword`/`lemma`를 따로 저장합니다. `went`→`go`, `hablo`→`hablar`처럼 검색에 함께 반환된 기본형을 선택할 수 있습니다. 별도의 추측형 형태소 분석은 하지 않습니다.
- 일본어는 `expKanji`와 `expEntry`로 표기와 읽기를 분리합니다. 루비 태그를 정리할 때 읽는 법이 예문 안에 중복되지 않게 합니다.
- 중국어는 제공되는 표기 및 성조가 포함된 병음을 저장합니다. 표제어를 임의로 간체로 변환하지 않습니다.
- 스페인어는 사전이 제공하는 명사 성/품사를 보관합니다. 발음기호가 제공되지 않으면 빈칸으로 두고 편집할 수 있습니다.
- 영어는 발음기호/품사를 보관합니다.
- 대표 예문은 그 항목의 뜻에 포함된 예문, 또는 동일 entry URL의 예문만 선택합니다. 다른 표제어의 검색 예문을 끼워 넣지 않습니다.
- HTML을 그대로 렌더링하지 않으며, 빈 응답·HTTP 오류·JSON 파싱 실패·구조 변경은 명확한 오류로 표시합니다. 결과 없음은 오류와 구분합니다.

공식 공개 API나 제휴가 아닌 개인 학습용 연동입니다. 네이버의 구조/접근 정책 변경, 접속 제한 또는 서버 위치에 따라 작동이 중단될 수 있습니다. 네이버 및 사전 제공처의 콘텐츠 권리는 각 제공처에 있습니다. 사전 데이터 전체를 저장소에 배포하지 않습니다. 원문 링크와 제공처를 표시하며 사용자가 고른 뜻만 기기에 저장합니다. 검색은 인터넷 연결이 필요합니다.

## PWA

HTTPS 배포 또는 localhost에서 설치할 수 있습니다. Android 브라우저의 앱 설치, iPhone Safari 공유 → 홈 화면에 추가를 사용합니다. 처음 접속하여 서비스 워커 캐시 준비가 끝나면 저장된 단어장과 학습은 오프라인에서 열립니다. 실제 iOS/Android 기기에 설치하여 확인한 것은 아니며 데스크톱 Chrome 모바일 뷰와 설치 가능 이벤트/매니페스트/캐시는 별도로 검증합니다.

## Vercel 배포

Vercel Hobby 플랜에서 GitHub 저장소를 가져오면 정적 PWA와 `/api/search` Node.js Function이 함께 배포됩니다. 프로젝트 설정은 `vercel.json`에 포함되어 있습니다.

1. Vercel에서 **Add New → Project**를 선택합니다.
2. GitHub의 `moschus1-alt/moa-vocab` 저장소를 가져옵니다.
3. 별도 설정을 바꾸지 않고 **Deploy**를 선택합니다.

CLI로 배포할 수도 있습니다.

```sh
npx vercel
npx vercel --prod
```

Hobby 플랜은 개인·비상업 프로젝트용 무료 플랜이며 사용량 한도가 적용됩니다. 네이버 사전이 Vercel 서버의 요청을 제한하거나 응답 구조를 바꾸면 검색이 중단될 수 있습니다.

## 다른 배포 방식

GitHub Pages는 정적 호스팅이라 네이버 프록시를 실행할 수 없습니다. 따라서 전체 앱은 서버 실행이 가능한 Sites 또는 Cloudflare Workers에 배포하는 구성을 제공합니다. 공개 GitHub 저장소는 소스 보관·수정 용도입니다.

```sh
npm run build
npx wrangler deploy
```

Cloudflare 계정 로그인이 필요하며 `wrangler.jsonc`에 정적 파일 및 API 라우팅이 설정되어 있습니다. 무료 플랜의 요청 한도와 정책은 계정에서 확인하세요. Sites에서는 `dist/server/index.js`와 `dist/client`를 패키징하여 동일한 Worker를 배포합니다. 설치 캐시가 바뀌는 릴리스에서는 `public/sw.js`의 캐시 버전을 올리세요.

## 구조

- `src/dictionary`: 네이버 응답 파서 및 클라이언트
- `src/course`: 과정 자료 로딩, 섹션·유닛 매핑
- `src/vocabulary`: IndexedDB 저장·중복·백업 검증
- `src/study`: 범위/랜덤 큐, 복습 간격, 학습 설정 및 양방향 입력 채점
- `src/ui`: 검색/단어장/학습 화면
- `public`: 모바일 스타일, 아이콘, PWA
- `server.mjs`: 로컬 HTTP 및 사전 프록시
- `worker.mjs`: 배포용 동일 origin API
- `tests`: 단위 검사와 실제 IndexedDB 브라우저 검증 화면

브라우저 검증 화면은 `MOA_TEST=1 PORT=4174 npm run dev`로 별도 서버를 띄운 뒤 `/__test`에서 실행합니다(PowerShell에서는 `$env:MOA_TEST='1'; $env:PORT='4174'; npm run dev`). 이 전용 origin은 빈 상태에서 사용해야 하며 실제 네이버 결과로 테스트 단어를 만듭니다. 제품 서버에서는 이 경로가 열리지 않습니다.
